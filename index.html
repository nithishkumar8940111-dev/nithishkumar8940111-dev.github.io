Four-Step Dataset Quality Assurance Methodology

STEP 01

Guideline-First Execution

Deconstruct project SOPs into concrete atomic-action boundaries, affordance, and occlusion rules before labeling.

STEP 02

Frame & Boundary Precision

Audit VLM auto-captions, automated video cuts, and model pre-labels against raw visual frames—catching hand swaps and boundary drift.

STEP 03

Evidence-Backed RLHF Reasoning

Tie every preference score to observable events (dropped items, arm oscillation, wasted retries) rather than generic labels.

STEP 04

Automated JSON Sanity Checks

Verify exported JSON files for contiguous frame intervals, schema consistency, and clean class names prior to delivery.
